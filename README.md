A one-page newspaper front page summing up Monday 23 November 2026 in a
single image: 40 stories from 7 regions, led by the Hormuz tanker strikes,
the AI market selloff, and the COP31 talks ending with no deal.

[Competition](https://make.fun/bounty/news-image-20261123)

## Run

`MAKEFUN_OUTPUT_DIR=<dir> python3 main.py` copies `entry.png` into
`<dir>/entry.png` and verifies it by SHA-256 and size. The image is
pre-rendered with a stdlib-only Python script; `main.py` uses only the
standard library.
